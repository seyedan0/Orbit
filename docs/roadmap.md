# نقشه راه خلاصه Orbit

برنامه اجرایی تفصیلی در [project-plan.md](project-plan.md)، فهرست تفکیکی قابلیت‌های آزاد در [feature-catalog.md](feature-catalog.md) و مبانی معماری کلان محصول در [product-architecture.md](product-architecture.md) مستند شده است.

## وضعیت فازها

| فاز | موضوع | خروجی‌های کلیدی | وضعیت |
| --- | --------------------------------- | ---------------------------------------------------- | ------------------- |
| 0   | کشف محصول و تصمیم‌های پایه        | مدل چرخه بهره‌وری، رسالت FOSS، نیازمندی‌ها و ADRها     | تکمیل مستندات اولیه |
| 1   | قراردادها، monorepo و Web         | ساختار پکیج‌ها، shared-types، اسکلت Web و CI         | تکمیل‌شده           |
| 2   | هسته دامنه و storage محلی Web     | ذخیره‌سازی محلی IndexedDB، تسک، نوت، چک‌لیست و Inbox  | تکمیل‌شده           |
| 3   | sync و حساب کاربری                | احراز هویت JWT، سرور NestJS، حل تعارض LWW و Tombstone | تکمیل‌شده           |
| 4   | مدیریت زمان و تقویم (شمسی/میلادی) | تقویم جلالی برکوفسکی، DatePicker دوگانه، Time-blocking| **در حال انجام**    |
| 5   | سازمان‌دهی، فیلترها و نماهای پیشرفته| فیلترهای JSON DSL، ماتریکس آیزنهاور، تایم‌لاین و LexoRank | برنامه‌ریزی‌شده     |
| 6   | Focus و Pomodoro                  | تایمر کار/استراحت متصل به تسک، Focus Mode بدون حواس‌پرتی | برنامه‌ریزی‌شده     |
| 6.5 | بازبینی قابلیت‌ها و بازطراحی UI/UX| دیزاین سیستم کامل، تم دارک و لایت، دسترس‌پذیری A11y   | برنامه‌ریزی‌شده     |
| 7   | عادت‌ها و روتین‌ها                | ردیاب نامحدود عادت‌ها، استریک، هیت‌مپ و اتصال به تسک | برنامه‌ریزی‌شده     |
| 8   | تحلیل‌ها، گزارش‌ها و بازبینی       | بازبینی روزانه/هفتگی، هشدار بار کاری و Task Debt      | برنامه‌ریزی‌شده     |
| 9   | همکاری و اشتراک‌گذاری             | فضای کاری (Workspace)، پروژه‌های مشترک و نقش‌ها       | برنامه‌ریزی‌شده     |
| 10  | یکپارچه‌سازی، هوش مصنوعی و اتوماسیون | هوش مصنوعی BYOK، پشتیبانی از Ollama، سرور MCP و CalDAV| برنامه‌ریزی‌شده     |
| 11  | انتشار و کیفیت production         | دسکتاپ Tauri، موبایل Android، تست پایداری و Self-host | برنامه‌ریزی‌شده     |

# واژه‌نامه

- **MVP:** کوچک‌ترین نسخه قابل آزمایش با ارزش مستقل.
- **Local-first:** local store برای عملیات روزمره اولویت دارد و شبکه شرط استفاده نیست.
- **Mutation:** رخداد تغییر یک موجودیت که باید به سرور منتقل شود.
- **Full Sync:** ارسال یا دریافت کامل entity.
- **Partial Sync:** ارسال تغییرات فیلدی به‌جای کل entity.
- **Cursor:** نشانگر موقعیت کلاینت در جریان تغییرات سرور.
- **Idempotency:** تکرار امن یک درخواست بدون ایجاد اثر اضافه.
- **Soft Delete:** علامت‌گذاری حذف بدون حذف فوری فیزیکی.
- **Tombstone:** رکورد یا نشانگر باقی‌مانده برای انتقال حذف در سینک.
- **Field-level LWW:** انتخاب مقدار جدیدتر برای هر فیلد، نه کل رکورد.
- **ADR:** Architecture Decision Record، ثبت تصمیم معماری و پیامدهای آن.

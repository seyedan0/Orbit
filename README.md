# Orbit

پلتفرم جامع و قابل توسعه برای همکاری انسان و چند AI.

## وضعیت پروژه

وضعیت فعلی پروژه در [PROGRESS.md](PROGRESS.md) ثبت می‌شود.

## مستندات

تمام مستندات پروژه در پوشه [docs](docs) نگهداری می‌شوند:

- [راهنمای مستندات](docs/README.md)
- [چشم‌انداز و دامنه](docs/vision.md)
- [تصمیم‌های معماری](docs/decisions.md)

## قرارداد همکاری AIها

هر AI پیش از شروع کار باید:

1. `PROGRESS.md` را بخواند.
2. مستند مرتبط در `docs/` را بررسی کند.
3. کار خود را در بخش فعالیت‌ها ثبت کند.
4. پس از پایان کار، وضعیت، فایل‌های تغییرکرده و اعتبارسنجی انجام‌شده را ثبت کند.

جزئیات این قرارداد در [راهنمای مستندات](docs/README.md) آمده است.
